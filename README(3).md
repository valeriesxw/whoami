# Valerie Su — Portfolio Website

This folder contains a static portfolio website that can be published free with GitHub Pages.

## Files

- `index.html` — the website content
- `style.css` — colours and layout
- `profile.jpg` — Valerie's profile photo
- `favicon.svg` — browser tab icon

## Publish with GitHub Pages

1. Sign in to GitHub and click **+** → **New repository**.
2. Name the repository `valerie-portfolio` and set it to **Public**.
3. Do not add a README, `.gitignore` or licence. Click **Create repository**.
4. On the repository page, click **uploading an existing file**.
5. Upload all four website files and this README. Keep every file in the repository's main area, not inside another folder.
6. Enter `Add portfolio website` under **Commit changes**, then click **Commit changes**.
7. Open **Settings** → **Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select the `main` branch and `/(root)` folder, then click **Save**.
10. Wait about two minutes. Your website will appear at:

   `https://valeriesxw.github.io/valerie-portfolio/`

## Update later

Edit or replace the relevant file in GitHub and commit the change. GitHub Pages will update the website automatically.
